These are the workloads I used in this paper to test my system (SpeedyLoader) and all baselines (PyTorch default DataLoader, Pecan, Nvidia-DALI). 
1. Directions
clone the repo:
```bash
git clone git@github.com:Rahm-no/eurosys-submission.git
```
2. cd to the directory of the workload you want to test. Example
```bash
cd image-segmentation
```
3. Follow the readme inside the workload for running the code
